# Movie Booking API



A backend REST API for a movie ticket booking system built using **ASP.NET Core Web API**, **Entity Framework Core**, and **SQL Server**.



The application provides APIs for managing movies, theaters, screens, seats, shows, users, and movie ticket bookings. It also includes **JWT-based authentication and authorization** to secure protected endpoints.



## Features



* User registration and login

* JWT-based authentication

* JWT authorization for protected APIs

* Movie management

* Theater management

* Screen management

* Seat management

* Show management

* Movie ticket booking

* Multiple seat selection

* Booking amount calculation

* Check seat availability for a particular show

* Prevent booking of already-confirmed seats

* View booking details

* Cancel bookings by updating booking status

* Entity Framework Core database integration

* SQL Server database

* Repository and Service layer architecture

* DTOs for API request/response handling

* RESTful API endpoints

* Swagger/OpenAPI support
